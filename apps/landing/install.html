❓ Frequently Asked Questions

Does AI CAGE send my data anywhere?
No. Never. All detection runs inside your browser on your own computer. AI CAGE has no servers. The source code is public on GitHub for anyone to verify.
Does it work without internet?
Yes, completely. All PII detection uses rules stored inside the extension — no internet needed to detect and cage your data.

🌐 Chrome blocked the download — how do I get the file?
Chrome sometimes blocks unsigned executables. Here's how to allow it:

Option A — Download bar:
1. Look at the bottom of Chrome for the download notification
2. Click the arrow ˅ next to the filename
3. Click "Keep" or "Keep anyway" ✅

Option B — Downloads page:
1. Press Ctrl+J to open Chrome Downloads
2. Find the AI CAGE file → click "Keep dangerous file"
3. Confirm → file is saved ✅

Option C — Use the .msi installer instead:
The .msi file is sometimes blocked less aggressively than .exe. Try downloading that version from the same page.
🔷 Microsoft Edge blocked the download — what do I do?
Edge has SmartScreen enabled by default. Steps to allow:

1. Click the 3 dots ··· next to the blocked download notification
2. Click "Keep"
3. A dialog appears — click "Show more" → "Keep anyway" ✅

Or: disable SmartScreen temporarily in Edge Settings → Privacy → Microsoft Defender SmartScreen → Off, then re-enable after install.
