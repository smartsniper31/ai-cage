❓ Frequently Asked Questions

Does AI CAGE send my data anywhere?
No. Never. All sensitive data detection happens inside your browser, on your own computer. No data leaves your device. AI CAGE has no servers. The full source code is public on GitHub for anyone to verify.
Does it work without an internet connection?
Yes, completely. The detection of sensitive data requires no internet connection. It uses only rules stored inside the extension itself.
What types of data does it protect?
AI CAGE protects: email addresses, credit card numbers, IBANs, Tunisian CIN, Matricule Fiscal, API keys, passwords, IP addresses, phone numbers, person names, passports, residence permits, and more — 15 types of sensitive data in total.
Is it free?
Yes, the basic version is completely free. It protects 15 data types, up to 100 operations per month, and includes Shadow AI detection. A Pro version (€5/user/month) is available for teams with advanced needs.
