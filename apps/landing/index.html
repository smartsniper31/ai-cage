How It Works

Three steps. Zero complexity. Your data never leaves the cage.

1️⃣

You type a prompt

Paste your message into ChatGPT, Claude, or Gemini as usual. It may contain emails, names, IBANs, API keys.

2️⃣

AI CAGE removes PII

Before the request is sent, AI CAGE replaces sensitive data with safe tokens like [CAGED_EMAIL_1]. 100% local — no server involved.

3️⃣

AI responds, you see your data

The AI response contains tokens. AI CAGE restores the original values locally before displaying. You see everything. The AI never did.

👤 You → 🔒 AI CAGE
cageText() — local → 🤖 Monster AI
sees [CAGED_EMAIL_1] ← 🔓 AI CAGE
uncageText() — local ← 👤 You
see original data

PII never crosses the network boundary. The AI provider never sees your real data.
